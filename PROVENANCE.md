# Project provenance

Meridian ATS is an independent implementation. Its UI, component structure, styles, assets, API, database models, and demo records were created for this workspace. No source files, screenshots, or visual assets were copied from the reference repository.

The high-level workflow was informed by Nikhil Malakar's [application-tracking-system repository](https://github.com/nikhilmalakar/application-tracking-system), whose README describes employer-created roles, candidate applications, coordinator review, recruiter screening, and shortlisting.

The downloaded reference folder did not contain a license file, and the GitHub repository listing does not show one. GitHub's [licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains that without a license, default copyright applies. Meridian therefore implements the documented product workflow in new code rather than disguising or repackaging that repository.
